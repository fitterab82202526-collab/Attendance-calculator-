ITI Records Website Prototype

Open index.html in Chrome. Login screen is modeled after the supplied ITI Records reference portal.
Seed data was generated from the supplied Excel workbooks and PDF text extraction.

Included: dashboard, 2026 master student list, Fitter detailed data, attendance, practical/LO marks, LO definitions, PDF report browser, export and local data backup.

For production use: add server-side authentication, database, role permissions, daily attendance entry, Excel .xlsx export, document/photo storage, audit log and automated PDF generation.
