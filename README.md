# ITI Trainee Attendance 2026-27

Basic GitHub Pages attendance website.

## Excel export
The Export Excel button exports **only the currently selected month** and the currently selected **trade filter**.

Excel columns are exactly:
1. Sr No
2. Student Name
3. Total Working Day
4. Present Day
5. Percentage

Working days exclude dates marked as holidays.

If a trade is selected, only that trade is exported. If All Trades is selected, all matching students are exported.

Other features:
- 159 trainees
- 10 Aug 2026 to 31 Jul 2027 calendar
- Present / Absent / Leave
- Holiday marking
- Instructor bulk attendance
- Search and trade filter
- Browser localStorage
