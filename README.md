# ITI Trainee Attendance 2026-27

Basic GitHub Pages attendance website for SHREE S K PATEL ITI KADI (GIA-509).

## Excel export
The selected **month** and **trade filter** control the export.

### Sheet 1 — Selected Month Summary
Exactly 5 columns:
1. Sr No
2. Student Name
3. Total Working Day
4. Present Day
5. Percentage

Only the selected month is used in this sheet.

### Sheet 2 — Date-wise Entry
Fast attendance-entry list:
- Date
- Trade
- Sr No
- Student Name
- Attendance

Every student is listed for every date in the selected month. Attendance uses:
- P = Present
- A = Absent
- L = Leave
- HOLIDAY = holiday date

The website also supports selecting a date and marking all filtered students Present/Absent/Leave at once.

Other features:
- 159 trainees from the Master Excel
- 10 Aug 2026 to 31 Jul 2027
- Trade filter and search
- Holiday marking
- Browser localStorage
- Below-80% highlighting
