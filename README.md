# ITI Trainee Attendance 2026-27

GitHub Pages-ready basic attendance website.

Period: 10 August 2026 to 31 July 2027
Institute: SHREE S K PATEL ITI KADI (GIA-509)

Files:
- index.html — complete basic website
- README.md — setup notes

Features:
- 159 trainee records loaded from ITI_ID_Master_Excel_2026.xlsx
- Name/enrolment search
- Trade filter
- Attendance calendar
- Present/Absent/Leave
- Monthly working-day settings
- August 2026 and September 2026 default to 10 working days
- Cumulative working/present calculation
- Below-80% highlighting
- CSV export that opens in Excel
- Browser localStorage for attendance

GitHub Pages:
1. Create/open a repository.
2. Upload index.html and README.md.
3. Enable Settings -> Pages -> Deploy from branch.
4. Open the generated Pages URL.

Note: This is the requested BASIC GitHub file. It intentionally avoids a backend/database.
