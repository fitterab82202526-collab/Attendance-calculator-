# ITI Attendance Final GitHub

Three-page GitHub Pages attendance system for SHREE S K PATEL ITI KADI (GIA-509).

- Attendance Entry
- Student Dashboard
- Excel Export
- Master student data embedded
- Shared localStorage attendance database across all three pages
- Attendance period 10 Aug 2026 to 31 Jul 2027
- Holidays, bulk entry, trade filters, student search
- ExcelJS export with ITI header, report title, trade context, filters, freeze panes, A4 landscape print setup, percentage formatting and <80% red highlighting

Upload `index.html` to a GitHub repository and enable GitHub Pages.
